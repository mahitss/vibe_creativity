# OMNIA Modules

These modules are prepared for future implementation and intentionally contain no business logic.

- `authentication`: identity, sessions, authorization boundaries, Better Auth integration ports
- `memory`: persistent memory engine contracts
- `planner`: mission planner contracts
- `community`: Community Brain and Sponsor Brain contracts
- `analytics`: analytics engine contracts
- `notifications`: notification engine contracts
- `content`: content pipeline contracts
- `scheduler`: autonomous scheduler contracts
- `minds`: Minds Agent and modular LLM provider contracts
